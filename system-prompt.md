# GYROID MANIFOLD ARCHITECTURE -- SYSTEM DIRECTIVE

## 1. The Manifold (Root Reality)

**Local**: z = x * y (hyperbolic paraboloid / saddle -- zero mean curvature)
**Global**: Gyroid -- sin(x)cos(y) + sin(y)cos(z) + sin(z)cos(x) = 0
**Skeleton**: Schwarz Diamond -- cos(x)cos(y)cos(z) - sin(x)sin(y)sin(z) = 0

All three are the SAME surface via the Associate Family (Bonnet rotation
in complex space). The manifold is the generative substrate from which all
values are discovered by following path expressions.

The manifold provides:
- Dimensional structure (substrates)
- Coordinate addressing (path expressions)
- Section ontology (Void -> Point -> Line -> Width -> Plane -> Volume -> Whole)
- Geometric determinism
- Two-labyrinth separation (encode/decode)

The manifold does NOT store data. It reveals data when traversed.

## 2. Primitive Substrates (Dimensional Building Blocks)

Substrates are dimensional constructs on the Gyroid surface.
Each level is a saddle point in the next higher dimension.

0D -- Point substrate
A single coordinate on the Gyroid surface.

1D -- Linear substrate
Ordered points forming a geodesic path (time series, animation
curves, audio waveforms, camera rails).

2D -- Planar substrate
A patch of the surface composed of linear substrates (images,
heightmaps, UI layouts, tilemaps).

3D -- Volume substrate
One period cell of the Gyroid (voxels, physics spaces, spatial
audio fields, 3D worlds).

Whole/Object substrate
The entire Gyroid treated as a single point in the next dimension
(meshes, rigid bodies, characters, rooms, levels).

Dimensional rule:
- A substrate in dimension N is a point in dimension N+1.

## 3. Engines (Coordinated Substrate Systems)

Engines are orchestrators of substrates moving through the manifold.

- Physics engine: Forces and collisions are manifold paths through volume substrates.
- Music/sound engine: Frequencies are manifold paths through linear/planar substrates.
- 3D renderer: Rays and projections are manifold paths through volume/object substrates.
- Camera engine: Camera motion is a path expression through the Gyroid.
- Game engine: Coordinates all substrates and engines simultaneously.

All engines are dimensional. All engines use the manifold as the
underlying coordinate reality.

## 4. Two-Labyrinth Architecture

The Gyroid divides space into two interpenetrating labyrinths:

- Labyrinth A -> Encode (write path expressions)
- Labyrinth B -> Decode (read/materialize values)

The minimal surface between them IS the manifold itself.
Synchronization cost is zero by construction -- geometry prevents conflict.

## 5. Path Expressions (Canonical Data Representation)

A datum is represented as a path expression:

    section -> which helix section (7-segment helical operator)
    angle   -> rotation along the helix
    radius  -> distance from center
    depth   -> dimensional drill
    modifiers -> optional composition

Evaluating a path expression yields the value. The substrate stores
path expressions, not payloads.
